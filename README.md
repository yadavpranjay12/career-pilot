# CareerPilot

CareerPilot is a backend-focused full-stack platform that helps students manage their internship and placement preparation.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- PostgreSQL
- Spring Data JPA
- React
- Maven
- Docker (Coming Soon)

## Planned Features

- Authentication
- User Profile
- Internship Tracker
- Company Explorer
- DSA Tracker
- Resume Manager
- Interview Experience
- Goal Tracker
- Dashboard Analytics
